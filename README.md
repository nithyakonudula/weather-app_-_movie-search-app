# Minor Project 03 – Weather App & Movie Search App

## 📌 Project Overview

This project contains two interactive web applications developed using HTML, CSS, and JavaScript (ES6+).

The project demonstrates the use of:

- DOM Manipulation
- JavaScript ES6+ features
- Events and Forms
- Async/Await
- Promises
- Fetch API
- REST API Integration
- JSON Data Handling
- Error Handling
- Responsive Web Design
- JavaScript Modules

The two applications included in this project are:

1. 🌤️ Weather App
2. 🎬 Movie Search App

---

# 🌤️ 1. Weather App

The Weather App allows users to search for the current weather information of a city by entering its name.

### Features

- 🔎 Search weather by city name
- 🌡️ Display current temperature
- 🌤️ Display current weather condition
- 💧 Display humidity
- 💨 Display wind speed
- 🌡️ Display feels-like temperature
- ❌ Handle invalid city names and API errors
- 📱 Responsive design
- ⚡ Fetch real-time weather data using an API

### API Used

**OpenWeather API**

The application uses the OpenWeather API to retrieve current weather information.

---

# 🎬 2. Movie Search App

The Movie Search App allows users to search for movies by entering a movie name.

### Features

- 🔎 Search movies by title
- 🎞️ Display movie posters
- 🎬 Display movie titles
- ⭐ Display movie ratings
- 📅 Display release information
- 📝 Display movie details
- ❌ Handle invalid movie searches
- 📱 Responsive design
- ⚡ Fetch movie information using a REST API

### API Used

**OMDb API – The Open Movie Database**

The application uses the OMDb API to retrieve movie information.
